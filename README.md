# 직원 근태관리

직원 3명 규모의 모바일/PC 근태관리 웹앱입니다.

## 현재 구현된 데모
- 관리자/직원 분리 로그인 화면
- 관리자 월간 근태 현황 및 직원별 누적 근무시간
- 직원 오늘 출근/퇴근 버튼
- 초과근무 신청 및 관리자 승인/거절 UI
- 연차 사용/총량 표시
- 모바일 반응형 화면

## 데모 계정
- 관리자: `admin` / `demo`
- 직원: `employee1` / `demo`

> 현재 버전은 UI/동작 확인용이며 브라우저 메모리에서만 동작합니다. 실제 계정, 근태 데이터, 한국 공휴일, 연차, 휴직, 초과근무 승인 기록은 다음 단계에서 Supabase Auth/PostgreSQL에 연결합니다.

## 운영 규칙
- 평일 09:00 ~ 16:00
- 토/일 및 대한민국 법정·대체공휴일 휴무
- 오늘 날짜에서만 직원 출퇴근 입력
- 초과근무는 직원 신청 → 관리자 승인/거절
